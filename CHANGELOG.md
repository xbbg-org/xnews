# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Breaking

- `sec.gov` requests now fail closed with a `config` error unless `secUserAgent` or `userAgent` is set. SEC's fair-access policy requires a declared contact; the old `contact@example.com` default impersonated one.
- MSRB EMMA requests now require explicit `msrbAcceptTermsOfUse: true`. Accepting EMMA's Terms of Use is now the caller's recorded act.
- Transport failures now throw typed `XnewsFetchError` values with a machine-readable `code` (`config | network | http_status | timeout | aborted`). Provider warnings and errors include a credential- and sensitive-query-redacted effective URL.
- Transport defaults now fail closed instead of following whatever a host asks for: a response body is capped at a streamed 32 MiB (raise it with `SourceFetchOptions.maxResponseBytes`, as file downloads do), and a redirect is refused when it downgrades to HTTP, points at a non-public literal address, or would forward credentials, a body, or caller headers cross-origin (`allowCrossOriginRedirects` opts back in). A caller that relied on the previous permissive behavior must now say so explicitly.

### Added

- Added `./catalog`, `./parsers`, and `./asr` subpath exports. `@xbbg/xnews/catalog` is structurally network-free: its import graph never reaches the fetch layer.
- Added `parsePublishedAt` and `PUBLISHED_AT_PARSER_VERSION`. RSS/Atom and provider-native Finviz, GDELT, and EMMA dates now use one versioned derivation; invalid explicit dates fail closed, missing zones or offsets are read as UTC, and unknown formats are tagged `engine`.
- Added `ProviderResult.undatedExcluded` to report items dropped by a `since` or `until` window because they lack a parseable date.
- Added `ProviderError.code` and `SourceFetchOptions.redirect`; `"follow"` defaults to at most ten policy-checked hops while the injected fetch receives `"manual"` for each hop.
- `FIXED_FEEDS` entries now carry `suggestedMinPollSeconds`; new `PROVIDER_POLICIES` records capture per-provider operational facts, including SEC's 10 requests/second limit and declared-user-agent requirement and EMMA's terms; new `NEWS_ITEM_ID_SCHEME_VERSION` documents the `provider|guid-or-link|title` item ID derivation.
- `bun run release <patch|minor|major|X.Y.Z>` cuts a release: it verifies the checkout is clean and synced, runs the quality and packaged-install gates, bumps the manifest, promotes `[Unreleased]` to a dated section with fresh compare links, commits, and writes an annotated tag whose message is the release notes. `--dry-run` validates without changing anything.
- `npm-publish.yml` now cuts the GitHub release from the matching `CHANGELOG.md` section, so the tag, the npm tarball, and the GitHub release notes cannot drift apart.
- Added federal bank-regulator announcement feeds as fixed providers: FFIEC (`ffiec`), FDIC press releases and board notices (`fdic`), OCC news releases and bulletins (`occ`), and the CFPB newsroom (`cfpb`). Like other fixed feeds they are fetched whole, filtered locally against the subject, and marked as press releases.
- Added a structured-data lane beside the news lane: `DataSource` binds a scheduled data publisher's dataset to its transport, `fetchDataRelease` wraps any source in the news lane's non-throwing status taxonomy, and `createDataReleaseWatcher` polls until a release with a new `asOf` appears, deduplicating consecutive identical failures. New `NewsItem.kind: "data"` marks items bridged from data releases.
- Added CFTC Commitments of Traders as the first data provider (`fetchCotReport`, `cotDataSource`, `parseCotRows`, `cotReleaseToNewsItems`) over CFTC's free, keyless Socrata API: all seven datasets (legacy, disaggregated, and TFF in futures-only and combined variants, plus the CIT supplemental), rows typed per family with per-category positions and week-over-week changes, market presets (`COT_MARKETS`) with alias and historical-code resolution, network-free URL builders and column maps in `@xbbg/xnews/catalog`, a `cftc-cot` provider policy documenting Socrata throttling and the Friday 15:30 ET release cadence, and a `smoke:cot` live gate.
- Added FFIEC CDR bulk data as the second data provider (`fetchFfiecCallReport`, `ffiecCallDataSource`, `downloadFfiecBulkData`, `ffiecReleaseToNewsItems`): quarterly Call Report bulk archives fetched by driving the CDR page's stateful ASP.NET postback chain (session cookies plus `__VIEWSTATE` threading), a dependency-free ZIP reader over the runtime's `DecompressionStream`, and pure bundle parsers for single-period call reports, the four-period subset, and UBPR ratios/ranks/stats TSVs (`parseFfiecCallBundle`, `parseFfiecFourPeriodBundle`, `parseFfiecUbprBundle`). All six CDR bulk products are downloadable in their TSV/XBRL formats; network-free form builders, product registry, and period helpers ship in `@xbbg/xnews/catalog`, and an `ffiec-cdr` provider policy records the session-cookie and archive-size facts.
- Added `DataFetchOptions.ifNewerThan`, a skip hint the release watcher now passes with the last seen `asOf` so heavy sources (FFIEC's ~6 MB archives) can answer "nothing new" from a cheap page probe instead of re-downloading; `DataRelease.updatedAt` carries the publisher's revision stamp (FFIEC's "Call Updated") beside the reporting-period `asOf`.
- Added DTCC swap dissemination as the third data provider (`fetchDtccSliceCatalog`, `fetchDtccSliceEvents`, `fetchDtccCumulativeEvents`, `dtccSliceDataSource`, `dtccCumulativeDataSource`, `dtccReleaseToNewsItems`) over DTCC's free, keyless Public Price Dissemination: real-time intraday slices and cumulative end-of-day files for every CFTC and SEC asset class (credits, rates, equities, forex, commodities), trade rows normalized to typed identity/lifecycle/price fields with the full 100+ column row kept verbatim in `raw`, pure parsers (`parseDtccSliceCatalog`, `parseDtccTradeCsv`, `parseDtccTradeZip`) in `@xbbg/xnews/parsers`, and network-free URL builders plus the slice file-name parser in `@xbbg/xnews/catalog`.
- Added sequenced releases to the data lane for publishers that emit many releases per date: `DataRelease.sequence` orders releases within a day (DTCC slice IDs), `DataFetchOptions.afterSequence` requests the earliest unseen release, and `createDataReleaseWatcher` now drains sequenced backlogs in order without sleeping between polls, with `sinceSequence` for gap-free restarts.
- The dependency-free ZIP reader and the RFC 4180 CSV reader are shared infrastructure: `readZipEntries` (labeled errors, multi-disk rejection, ZIP64 per-entry sizes) backs FFIEC bundles, DTCC archives, EPUB, and CBZ, and `parseCsvRecords`/`parseCsvTable` handle quoted fields, escaped quotes, and embedded newlines for DTCC trade files. Both ship from `@xbbg/xnews/parsers` and the root export alongside `ZipEntry` and `MAX_ZIP_UNCOMPRESSED_BYTES`.
- Every decode is bounded, because DEFLATE expands by up to ~1032:1 and a payload that cleared the transport's byte ceiling can still exhaust memory. A ZIP entry must inflate to exactly the size its central directory declares, an entry declaring more than the archive's 512 MiB budget is refused before any decompression, and a PDF stream past 64 MiB is recorded as a per-object warning rather than materialized. CSV text that ends inside a quoted field throws instead of returning a shortened final record that would read as data.
- Added raw governed transport (`fetchRaw`, `postForm`) beneath the fetch layer: byte-preserving responses with content type, disposition, and observed `Set-Cookie` values, sharing `fetchText`'s timeout, redirect, policy-header, and error semantics.
- Added the `hf-transcripts` provider: full earnings-call transcripts (~685 US large-cap issuers, 2005 onward) fetched keylessly from the Hugging Face datasets-server over the MIT-licensed `kurry/sp500_earnings_transcripts` snapshot. `fetchEarningsCallTranscripts` returns typed transcripts with speaker-attributed turns, `fetchEarningsCallTranscriptNews` bridges them into company feeds (opt-in via `sources`), and the generic `hfDatasetRowsUrl`/`hfDatasetFilterUrl`/`hfDatasetSearchUrl` builders reach any public dataset served by datasets-server, network-free from `@xbbg/xnews/catalog`.
- Added curated company-commentary packs: `SEC_COMMENTARY_QUERIES` (EDGAR full-text queries for prepared remarks, furnished transcripts, fireside chats, and investor days in 8-K exhibits) and `COMPANY_COMMENTARY_YOUTUBE_CHANNELS` (verified channels where executives speak in their own words, for `fetchYoutubeSubscriptions`).
- Added `fetchAlphaVantageTranscript`/`parseAlphaVantageTranscript` over Alpha Vantage's `EARNINGS_CALL_TRANSCRIPT` endpoint as the opt-in keyed complement to `hf-transcripts` (same keyed pattern as `openalex`): one fiscal quarter per request, speaker-attributed turns with roles and upstream per-turn sentiment, free-tier keys at 25 requests/day, and the `apikey` query value redacted from reported URLs and errors.
- Added FRED structured data: series search/detail/observation URL builders, fetchers, and pure parsers; typed observation pages; and `fredDataSource` for `fetchDataRelease`/watcher integration without adding FRED to `NewsProvider`. FRED request URLs redact API keys, and `FRED_PROVIDER_POLICY` records key, rate, terms, and attribution requirements.
- Added typed `ResearchPaper` metadata and standalone arXiv search/announcement, OpenAlex Works, BIS Working Papers, and BIS Central Bank Research Hub snapshot/recent APIs. Opt-in company/topic providers are `arxiv`, `openalex`, `bis-research`, and `bis-research-hub`, configured through `arxivCategories`, `openAlexApiKey`, and `bisInstitutions`; merged duplicates retain `seenInProviders` and per-source `provenance`.
- Added 29 opt-in central-bank news/speech fixed feeds and 13 opt-in research feeds, exported as `CENTRAL_BANK_NEWS_PROVIDERS` and `CENTRAL_BANK_RESEARCH_PROVIDERS` for whole-group selection alongside direct provider IDs.
- Added a works lane beside the news and data lanes for bibliographic catalog lookup: a `WorksSource` binds one catalog to its transport, `searchWorks` wraps it in the shared non-throwing status taxonomy, `searchWorksAcross` merges several catalogs while degrading per source, and `mergeWorkRecords` deduplicates on ISBN-13, DOI, or content MD5 before falling back to a normalized title/author/year/format key. `resolveWorkIdentity` recovers identifiers for a record that states none by scoring it against an authoritative catalog, keeping `origin` and `confidence` on the identity so a fuzzy match can never be mistaken for a stated one. `WorkAvailability` records catalog access signals and defaults to `unknown` when none is reported.
- Added four works providers. `open-library` and `internet-archive` use stable official APIs and carry their own origin; `internet-archive` constrains every query to `mediatype:texts` and phrase-quotes free text, which the search backend would otherwise OR into unrelated periodicals. `libgen` and `annas-archive` are mirror-based and rotate domains, so every URL builder requires a caller-supplied origin. Pure parsers (`parseLibgenBooks`, `parseAnnasArchiveRecords`, `parseInternetArchiveWorks`, `parseOpenLibraryWorks`) ship in `@xbbg/xnews/parsers` with the network-free URL builders in `@xbbg/xnews/catalog`.
- Added mirror pools for the catalogs that rotate hostnames: `parseMirrorList` reads a deployment-local INI-ish list of named pools, `loadMirrorList` reads one from `mirrors.local.txt` or `XNEWS_MIRRORS_FILE`, and `withMirrorFailover` tries a pool in order. Only a failed request advances to the next mirror — a mirror that legitimately matched nothing ends the search rather than being masked by the next mirror's hits — and every mirror that failed first is named in the page warnings. Non-HTTPS origins are rejected at parse time because the transport refuses them at request time.
- Added `extractIsbns`, shared checksum-validating ISBN extraction over free text, so every catalog adapter reaches the same verdict on a candidate run; `parseByteSize` moved to the shared text helpers behind its existing export.
- Added file retrieval for works-lane records: `resolveWorkFiles` turns a `WorkRecord` into candidate file URLs, `downloadFile` fetches one, and `downloadWork` does both and returns the first candidate that answers. Bytes are never decoded, so any file type passes through intact, and the response ceiling is raised to 2 GiB because the shared 32 MiB default rejects most scanned PDFs. Library Genesis mints a single-use `key` on its mirror page, so that page is fetched to obtain it; Internet Archive resolves through `/metadata/<id>`; Anna's Archive uses its documented `fast_download.json` API when `annasArchiveKey` is supplied.
- Added `SourceFetchOptions.allowCrossOriginRedirects`, which downloads set by default: catalogs mint a token on their own host and redirect to a CDN, which the transport otherwise refuses whenever a caller User-Agent, sensitive query parameter, body, or extra header is present. A redirect into a private network address is still refused.
- Added `extractText`, which decodes EPUB, PDF, DjVu, MOBI/AZW/AZW3, CBZ, plain text, and HTML with no runtime dependency. EPUB is read through the existing ZIP reader by walking the OPF spine, so chapters come out in reading order and cover/navigation documents stay out of the body; MOBI-family files are PalmDOC LZ77 inside a PDB container; CBZ enumerates its page images in natural order because a comic carries no text layer. CBR throws a `config` error naming RAR as the missing decoder rather than returning empty text.
- Added a native PDF text decoder (`extractPdfText`). It collects objects by scanning for `N G obj` rather than trusting the cross-reference table, which real catalog files routinely rebuild or damage, then expands `/ObjStm` compressed object streams — two of three sampled files from arXiv, BIS, and the Internet Archive carry 30+ of them, so skipping those would lose most of the document. Supports Flate, ASCIIHex, ASCII85, and RunLength filters plus PNG predictors, walks the text operators, and maps glyph codes through each font's `/ToUnicode` CMap; a composite font is identified by `/Subtype /Type0` rather than by its code values, because a Type0 font addresses glyphs with two-byte codes even when those codes are small. Measured on real files: arXiv 1706.03762 (`arxiv.org/pdf/1706.03762`) is 15 pages and 35,504 characters in about 100 ms, and a 12.3 MB, 1,306-page copy of CLRS is 5,481,690 characters in about 3.4 s.
- Added OCR for scanned PDFs (`ocrImages`, `extractPdfImages`, and `ExtractOptions.ocr`). A scan stores each page as a `/DCTDecode` image XObject whose stream bytes already are a JPEG, so pages are extracted directly with no PDF renderer. Images are sent to any OpenAI-compatible `/v1/chat/completions` endpoint; defaults follow Baidu's Unlimited-OCR recipe (`temperature: 0`, `skip_special_tokens: false`, `gundam`/`base` image modes, its `<image>` prompts), with `customLogitProcessor` for SGLang's repeat suppression, which vLLM rejects and so is omitted unless set. Pages are batched because a long book overruns a 32k context, and a failed batch is reported with its page range instead of silently shortening the result. Without an `ocr` server a scan still throws rather than returning empty text.
- Added a native DjVu hidden-text decoder (`extractDjvuText`, returning `DjvuText`). Implemented from the published DjVu Reference v3 rather than from djvulibre or djvu.js, both of which are GPL-2 and so cannot be used by an Apache-2.0 package: an IFF walker (including the even-length chunk padding that silently desynchronises a walk when missed), the Z′-Coder adaptive binary arithmetic decoder of Appendix 3, and the Appendix 4 BZZ codec — Burrows–Wheeler with the frequency-rotated quasi-MTF. Measured against the specification's own DjVu edition (`DjVu3Spec.djvu`, 462 KB): 71 pages and 155,747 characters in under 150 ms. A DjVu with pages but no text layer throws the same OCR-suggesting `config` error as a scanned PDF.
- `postJson` now accepts a `RawRequestInit`, so a caller can attach per-request headers such as an `Authorization` bearer token; host policy headers still win on collision.
- Added nine opt-in research providers beyond arXiv/OpenAlex/BIS: NBER working papers (`nber`, native `q` search plus the official RSS feed), SSRN network listings (`ssrn`, `ssrnNetworks` accepts `fen`/`arn`/`ern` or any numeric binding id), Crossref Works (`crossref`, full `filter`/`select`/sort/cursor surface plus feed-level `crossrefFilters`), World Bank Documents & Reports (`world-bank`, `worldBankDocTypes` and native date ranges), bioRxiv and medRxiv preprints (`biorxiv`/`medrxiv`, `bioRxivCategories`), Europe PMC (`europe-pmc`, query-language passthrough with cursor paging), Hugging Face daily papers (`hf-papers`), and OSF preprints (`osf-preprints`, `osfProviders`). Providers with native search and date filters (`crossref`, `europe-pmc`, `world-bank`) forward `since`/`until` upstream; listing-style providers are fetched whole and filtered locally like `bis-research`.
- The root export exposes the lower-level pieces of the new lanes so a consumer can compose them without reaching into module paths: mirror pools (`mirrorPool`, `mirrorBaseUrls`, `resolveMirrorsFile`, `DEFAULT_MIRROR_POOL`, `DEFAULT_MIRRORS_FILE`, `MIRRORS_FILE_ENV`), download plumbing (`DEFAULT_DOWNLOAD_MAX_BYTES`, `dispositionFileName`), and work identity (`emptyWorkIdentity`, `isbnIdentity`, `isbn10To13`, `normalizeIsbn`, `normalizeDoi`, `workMatchScore`), each with its result, option, and provenance types.
- Added `mirrors.example.txt`, a copyable template for the `libgen` and `annas-archive` pools; `.gitignore` now excludes `mirrors.local.txt`, because a deployment's chosen origins are not a fact about the package.
- `WORKS_PROVIDER_POLICIES` now covers every works provider by type, adding Internet Archive (official keyless APIs, unpublished rate ceiling, borrowable is not redistributable) and Anna's Archive (rotating unofficial mirrors, membership-keyed `fast_download` with a daily allowance). A new catalog can no longer ship without its operational facts.
- Added live gates beside the fixture suite for the paths that only a real upstream exercises: `smoke:cot`, `smoke:ffiec` (stateful postback chain, call-report archive, and a UBPR bulk report), `smoke:dtcc` (slice catalog, slice, and cumulative files), `smoke:research` (every research provider), and `smoke:works` (bibliographic catalogs and file resolution).

### Changed

- Default User-Agent strings no longer embed the package version, which could drift.
- Library Genesis and Internet Archive catalog timestamps now derive through `parsePublishedAt` like every other date in the package, and refuse an `engine`-tagged result: a bibliographic year is not an ingest instant.
- RSS/Atom and new research/data JSON adapters now fail closed on malformed, truncated, wrong-root, or schema-incompatible responses without copying response content into diagnostics; XML block scanning is linear, bounded to 256 levels of nesting, and invalid numeric entities no longer abort a feed. RSS reads a `date` element when a feed omits `pubDate`, and Atom prefers `published` over `updated`, so an item carries its publication time rather than the time it was last revised.
- Multi-URL fixed-feed providers preserve successful siblings as `partial`, news watchers surface total provider outages, and arXiv/OpenAlex retain requested limits while forwarding category/date constraints upstream.
- Data releases with zero rows are successful dated releases rather than no-data results; data watchers reject malformed checkpoints before polling and reject invalid release dates or sequences without poisoning their checkpoint.
- A response that breaches the byte ceiling now names `maxResponseBytes` in its message, because the fix is to raise the ceiling and the old wording did not say so. The code stays `network`: `config` is reserved for preconditions a caller must satisfy before a request is attempted, which both lanes report as `disabled`.
- The npm description and keywords now name research papers, central-bank publications, structured economic data, and the document formats the package reads (`epub`, `pdf`, `ocr`, `text-extraction`, `open-library`), so registry discovery reflects the package's lanes rather than market news and transcription alone.

## [0.1.1] - 2026-07-28

### Changed

- Published by CI through npm trusted publishing (OIDC), so the tarball carries a provenance attestation. `0.1.0` was published from a maintainer token and has none.

## [0.1.0] - 2026-07-28

### Added

- Company, topic, and watchlist news feeds over 36 free, keyless public providers.
- SEC EDGAR company, current, and full-text filing sources; MSRB EMMA municipal continuing disclosures; Federal Register and CourtListener.
- 22 fixed market and wire feeds filtered locally against the subject.
- YouTube channel subscriptions, caption transcripts, and realtime audio transcription via local Moonshine or hosted OpenRouter backends.
- Injected `fetch`, `timeoutMs`, and `signal` support across every provider.
- Apache-2.0 `LICENSE` and full npm release metadata (`repository`, `homepage`, `bugs`, `keywords`, `author`, `engines`, `publishConfig`).
- `./package.json` subpath export so tooling can resolve the manifest through the package name.
- `npm-publish.yml` workflow publishing through npm trusted publishing (OIDC) with provenance attestation on `vX.Y.Z` tags.
- Packaging validation gates: `publint`, `@arethetypeswrong/cli`, and a `smoke:packaged-install` test that installs the packed tarball into a throwaway project and exercises the public entrypoint under plain Node.

### Fixed

- Published bundle now links its source map. `--sourcemap=external` emitted `dist/index.js.map` without a `sourceMappingURL` comment, shipping ~308 KB of unreachable data.
- Declaration maps no longer point at `../src`, which is not part of the published tarball; `declarationMap` is disabled for the build config.
